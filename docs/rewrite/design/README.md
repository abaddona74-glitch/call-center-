# Эталоны дизайна (скриншоты legacy UI)

Новый фронт должен выглядеть **так же**. Токены (цвета, шрифты, радиусы, тени, анимации) — в [`tokens.md`](tokens.md).

## Как сняты

- Код: `legacy/` из ветки `rewrite/foundation` после коммита `001891b` (фронт синхронизирован с продом 2026-11-17).
- Запуск: копия `legacy/` вне репозитория, админка на 3535, портал операторов на 3005. Все внешние хосты (АТС, AMI, SSH/SFTP, Redis, SMTP, Telegram, Gemini, Proxmox) указывали на закрытые локальные порты, исходящие соединения на не-loopback адреса блокировались на уровне Node.
- Данные **полностью фейковые**: ~2 600 строк CDR за 10 дней в одноразовом MariaDB-контейнере (те же SQL-запросы legacy, что на проде), SQLite наполнен через собственный init-код legacy (`authService.createUser` и т.д.), живое состояние AMI (операторы, разговоры, очередь) подставлено в память, записи — сгенерированные WAV. Номера случайные, имена операторов и клиентов выдуманы. Захардкоженные в legacy-коде реальные имена сотрудников в копии заменены на выдуманные; справочник ответственных (`admin-25`) размыт.
- Снимки: headless Google Chrome через `playwright-core`, viewport **1440×900**, `deviceScaleFactor: 1`, локаль `uz`, `Asia/Tashkent`; узкая ширина — **390×844** (`mobile-*`). Файлы `*-full.png` — вся страница целиком.
- Пользователи: `admin` (superuser, все вкладки), `superuser` («Boss», без вкладки Statistika), `op101`/`op104`/`op105` (операторы основной группы 100–199), `op201`/`op202` (группа «Zangiota» 200+, создают тикеты).

## Общие наблюдения

- Тёмная тема везде; фон с двумя радиальными свечениями (индиго слева сверху, циан справа снизу).
- Правая панель «Jonli Monitor» (385px) **перекрывает** правую часть контента и шапки на 1440 — это поведение legacy (сравните `admin-02f-*` со свёрнутой панелью). В новом UI лучше сжимать контент, но размеры и порядок блоков панели сохранить.
- Активная вкладка шапки — «таблетка» с подсветкой `#6366f1`; KPI-карточки — цветная полоска сверху по смыслу метрики.
- Модалки: стекло (`blur`), радиус 16–20px, появление `scale(.96)→1` за 280ms, фон страницы затемнён и размыт.
- Номера телефонов всюду дополняются сохранённым именем клиента в скобках и бейджем оператора связи (Beeline, Ucell, Mobiuz, Humans, Uztelecom).
