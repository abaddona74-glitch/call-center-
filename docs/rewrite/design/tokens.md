# Дизайн-токены legacy UI

Источник: `legacy/public/css/style.css` (11 074 строки, админка 3535), `legacy/viewer/public/css/style.css` (5 953, портал операторов 3005), `legacy/viewer/public/css/tickets.css` (2 482), плюс замер **вычисленных** стилей на живых страницах (dashboard, history, viewer, tickets при 1440×900, данные фейковые — см. `README.md`). Где CSS-переменная и реальный рендер расходятся, верить рендеру: в legacy много инлайновых стилей в HTML/JS.

Тема одна — **тёмная**. Светлой темы в legacy нет (кроме светлой палитры студийного плеера). В новом фронте светлая тема добавлена поверх тех же токенов — см. `apps/web/src/app/styles/index.css` и CONVENTIONS.md; значения тёмной темы = legacy.
